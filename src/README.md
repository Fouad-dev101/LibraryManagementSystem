# Library Management System

A console-based library management system built in Java to practice OOP, inheritance, ArrayList, and file I/O.

## Features
- Add books and ebooks
- Add students
- Borrow and return books
- List all books and students

## Structure
- `Book.java` — base class
- `EBook.java` — extends Book
- `Student.java` — student with borrowed books
- `Library.java` — manages books and students
- `Main.java` — entry point

Work in progress. Next: console menu, file I/O.
